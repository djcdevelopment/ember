- **Cross-repo dependency**: `ember`’s Reflect feature relies on `leopard`’s Explorer and Ask infrastructure (e.g., `GraphContext`, `property-catalog`), but no integration tests are visible in the evidence.  
- **Windows phase alignment**: `ember` now uses llama.cpp Vulkan, but `vllama`’s resident-aware logic may conflict with llama.cpp’s memory model—no validation of this interaction in evidence.
